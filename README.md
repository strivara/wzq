# 五子棋 Gomoku

一个零依赖的五子棋小游戏，包含两种玩法：

- **人机对战**（单页，纯前端，可直接部署为静态网站）
- **联机对战**（WebSocket 服务端，两人通过房间号远程对弈）

整个项目只有一个 `index.html` 需要静态托管，联机对战额外需要一个 Node 服务端（`server.js`，仅用 Node 内置模块，**无需 `npm install`**）。

---

## ✨ 功能特性

### 人机对战
- 15×15 标准棋盘，玩家执黑先行，AI 执白
- 鼠标悬停交叉点显示半透明落子预览，最后一手红圈标记
- AI 启发式威胁评分：自动封堵你的活四/冲四，并抢自己的五连（进攻优先级略高于防守）
- 右侧面板：实时状态、比分（黑/白胜局）、回合数
- 「重新开始」「悔棋」（撤销你+AI 一回合）按钮
- 「AI 先手」开关：打开后你执白，AI 先走

### 联机对战
- 房间号制：双方输入**相同房间号**即进入同一对局
- 服务端权威判定胜负，客户端只负责渲染，避免作弊/不同步
- 先进入者执黑（先手），后进入者执白
- 落子实时同步、回合自动翻转
- 对手掉线提示、一键「重新开始」清盘
- 内置简单文字聊天
- 一键复制房间号，方便发给朋友

## 🚀 本地运行

### 人机对战（最简单）
直接用浏览器打开 `index.html` 即可，无需任何服务。

### 联机对战（需启动服务端）
```bash
# 使用项目自带的 Node 运行（需 Node 16+）
cd gomoku
node server.js
```
启动后默认监听 `3000` 端口，可用环境变量 `PORT` 覆盖。

浏览器打开：
- 人机对战：`http://localhost:3000/`
- 联机对战：`http://localhost:3000/multi`

**本机/局域网测试对弈**：开两个浏览器标签页进入 `/multi`，填**同一个房间号**即可开局。同一 WiFi 下的手机或其他电脑，把 `localhost` 换成你电脑的局域网 IP（如 `http://192.168.x.x:3000/multi`）也能进。

> npm 启动：`npm start`（等价于 `node server.js`）

## ☁️ 部署到公网（让异地朋友一起玩）

联机对战需要真正运行 `server.js` 的 Node 环境，普通静态托管（如纯 HTML 托管）**无法**支撑 WebSocket。本项目已配好多家平台的部署文件，连接仓库即可一键上线。

### 方式 A：Railway（推荐，无冷启动、免费额度）
1. 打开 https://railway.app ，用 GitHub 登录
2. **New Project → Deploy from GitHub repo**
3. 选择本仓库
4. Railway 自动读取 `railway.json` / `Procfile` 并运行 `node server.js`，注入 `PORT`
5. 部署完成后点 **Generate Domain**，得到如 `https://wzq-production.up.railway.app`
6. 把这个链接的 `/multi` 路径（如 `https://你的域名/multi`）发给朋友，双方填同一房间号即可异地对弈

### 方式 B：Render（免费，但有休眠）
1. 打开 https://render.com ，用 GitHub 登录
2. **New → Web Service** → 连接本仓库，Render 自动读取 `render.yaml`
3. 得到如 `https://wzq.onrender.com/multi`
4. ⚠️ 免费实例 15 分钟无访问会休眠，首次打开需等待几秒冷启动

### 其他方式
- **Heroku**：已提供 `Procfile`，按平台指引连接仓库即可
- **Vercel / Netlify**：仅适合部署人机对战（`index.html`），不支持 WebSocket 服务端
- **自有云服务器 / Docker**：在能运行 Node 的环境执行 `npm start`，用 Nginx 等反向代理暴露 3000 端口并配置 HTTPS

## 🎮 玩法说明

### 人机对战
你执黑子先手，点击棋盘交叉点落子，AI 随后自动应手。任意一方连成五子即获胜。

### 联机对战
1. 一人创建房间：随意输入一个房间号（如 `8888`）和昵称，点击「加入房间」
2. 把房间号发给朋友，朋友在「联机对战」页输入**同一个房间号**和昵称加入
3. 两人到齐后自动开局，先到者执黑先手
4. 落子后对手实时可见，轮次自动切换
5. 任意一方连成五子，服务端判定胜负并广播结果
6. 想换对手/重开：点击「重新开始」清盘；若对手掉线，会收到「对手已离开」提示

## ⚙️ 技术说明

- **服务端**：`server.js` 使用 Node 内置 `http` 模块，手写实现了 WebSocket 握手与帧编解码，因此**不依赖任何 npm 包**，clone 下来即可 `node server.js` 运行。
- **胜负判定**：服务端为权威方，对四个方向（横、竖、两斜）进行连子检测，避免客户端不一致。
- **房间隔离**：房间号作为唯一键，未指定则服务端自动分配；每房间最多 2 人。
- **端口**：优先读取环境变量 `PORT`，未设置时回退到 `3000`。
